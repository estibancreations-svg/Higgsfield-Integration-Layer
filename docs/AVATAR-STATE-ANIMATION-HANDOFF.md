## Provider adapter contract

Preflight requested references, camera/performance/text/audio controls, duration/timebase, supported models, quotas and cost against a current provider capability record. Preserve desired control separately from support status; no tutorial's historical UI setting becomes an API promise.

Transmit selected approved references and immutable IDs/hashes. Store sanitized input manifests/receipts, task IDs/status, output hashes, actual duration/usable intervals, model/prompt versions and error/retry/cost history. Explicitly report excess references and unsupported phoneme, rig, end-frame, compositing or camera controls; never silently truncate the reference set.

Analysis results preserve source URL, job ID, returned range, descriptor confidence, corrections and known omissions. A completed job can describe only an introduction. Do not store third-party full dialogue/lyrics/transcripts as the specification. A descriptor is not an avatar lock, frame annotation, camera solve or measured material/latency.

Handoff acceptance: actual references loaded, identity/coverage/continuity QC passed, contact/perception/effects timing reviewed, exact text/audio handled by supported stages, and a reproducible package with open holds. This documentation does not add API routes, keys, model integrations or generation runs.

## Change and source rules

Pinned versions and immutable asset hashes govern handoff. Record cause/scope/before/after/approver/source and targeted stale descendants. Preserve prior approved states and source uncertainty. Approved appearance outranks descriptive shorthand; ethnicity, language, accent and identity are separate. Do not overwrite corrected Black/fat representation through stylization or an older text description.

The full-coverage expansion is eight directions × eight configured heights = 64 full-body slots plus separate details; exact camera calibration remains unresolved. Keep older approved 32 masters and wardrobe-only 16 variants usable, and do not certify archived 24 studies as full coverage.
